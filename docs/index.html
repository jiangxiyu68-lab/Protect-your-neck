安装

1. 从 Releases 页面下载 颈椎守护-x.y.z-release.apk
2. 手机上点开安装（需允许「安装未知来源应用」）
3. 授予相机权限 → 点「开始守护」

首次打开建议把手机侧放，镜头能拍到侧脸与肩膀；正面对着镜头时测不出头前倾，App 会标注「角度不可信」且不计分。
