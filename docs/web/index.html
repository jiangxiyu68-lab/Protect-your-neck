怎么用才准

30 秒自测
  1. 镜头与肩同高，能同时拍到侧脸 + 肩膀；手机侧放或与视线斜 45°。
  2. 看右上角「视角」：0° 最准，30° 以内可用，>50° 会显示角度不可信，此时请转身。
  3. 挺直坐 10 秒，CVA 应 ≥ 75°、负荷 ≈ 5~8 kg；低头看手机，CVA 下降、θ 上升、负荷上升。
  4. 戴头戴式耳机时耳点会抖，程序自动改用「鼻—肩」降级测量（读数条标「鼻测」）。
  5. 光线充足、背景别太乱；实测帧率显示在画面右上角。

健康提醒，非医疗诊断。角度为摄像头估算值，个体差异、镜头高度都会影响读数，请关注自己的变化趋势，而不是绝对数字。

如实说明
  • 不是后台守护。浏览器标签页切到后台会暂停检测，回来续上；Android 版能锁屏常驻，网页版做不到。
  • 必须 localhost 或 https。直接双击 index.html、手机走局域网 http://192.168.x.x 都拿不到摄像头。
  • 帧率因设备而异。桌面独显/核显通常更流畅，手机与 CPU 推理更慢；以画面右上角的实测值为准，这里不写「流畅」。
  • 视角 > 50° 时数值不可信，程序会标红并停止计入统计——正对镜头测不出头前倾。
  • 功能比 App 少。网页版没有放松操、成长积分/衣橱、CSV 导出；这些在 Android 版里。
  • 非医疗诊断。只是提醒工具，不能替代医生。

开始前，先说清楚隐私

这个网页版在浏览器里自己算，没有服务器。

  • 画面只在本机处理。摄像头帧只交给浏览器内的 MediaPipe 模型，不录制、不保存、不上传。
  • 关键点不上传。耳朵、鼻子、肩膀的坐标算完就丢，只把「安全 / 注意 / 危险」的秒数存进浏览器 localStorage。
  • 不联网也能用。首次加载需要下载 MediaPipe 的 JS/WASM（CDN）；模型默认用本地文件。下载的只有代码和模型，没有你的画面。
  • 没有账号、没有追踪、没有广告。统计可在设置里一键清除。
  • 不构成医疗建议。这是健康提醒工具，不能替代医生诊断。
