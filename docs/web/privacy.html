隐私说明

颈椎守护 · 网页版（浏览器端坐姿监测）

一句话：摄像头画面只在你自己的浏览器里计算，不录制、不保存、不上传。 统计只写入你本机的 localStorage，清一下浏览器数据就没了。

1. 摄像头画面怎么处理

  • 点击「开启摄像头」后，浏览器会请求一次摄像头权限；你可以随时拒绝或在地址栏撤销。
  • 每一帧画面交给浏览器内运行的 MediaPipe 姿态模型推理，得到耳、鼻、肩的坐标，随后立即丢弃。
  • 画面不录制、不做截图、不写入磁盘、不发送到任何服务器。
  • 网页版没有「上传」接口，也不含任何第三方统计 / 广告 / 埋点 SDK。

2. 保存了什么

只会把下面这些不含图像的数据写进浏览器的 localStorage：

  • cervicalguard.web.stats.v1：每天「安全 / 注意 / 危险 / 角度不可信」的秒数与提醒次数
  • cervicalguard.web.settings.v1：阈值、提醒时长、帧率上限、声音/震动开关
  • cervicalguard.web.theme.v1：深色 / 浅色 / 跟随系统的偏好
  • cervicalguard.web.privacyAck.v1：你是否看过这份说明

设置 →「清空全部本地数据」可一键删除以上内容；也可在浏览器设置里清除站点数据。

3. 哪些请求会联网

  • MediaPipe 的 JS / WASM：首次开始守护时从 CDN（jsDelivr / unpkg）下载推理库。请求只包含这些代码文件，不包含你的画面或关键点。部署者可把 WASM 放到本地 assets/wasm/ 后完全离线运行（见 README）。
  • 姿态模型：默认使用本地文件 assets/pose_landmarker_lite.task（5.5MB）；仅当本地文件缺失时才回落到 Google 的模型下载地址。
  • 除此之外没有网络请求：没有账号、没有登录、没有云同步。

提示：即便不联网，已加载过的库在浏览器缓存有效期内仍可继续工作；模型在本地时整站可离线使用。

4. 不做什么

  • 不做人脸识别、不识别身份、不建立人脸档案。
  • 不收集设备标识、位置、通讯录等任何与坐姿无关的信息。
  • 不向第三方出售或共享任何数据（没有可共享的数据）。

5. 健康声明

本工具通过摄像头估算头前倾角与颈椎等效负荷，用于日常姿势提醒。它是健康提醒工具，不是医疗器械，不提供诊断、治疗或矫正建议。如有颈部疼痛、麻木等症状，请咨询医生。

6. 与 Android 版的区别

Android 版把统计存在 App 私有目录的数据库里；网页版存在浏览器 localStorage 里，两者互不同步。Android 版不申请网络权限，网页版需要联网下载一次推理库（之后可离线）。详见 完整隐私政策（部署到 GitHub Pages 后可用）。

7. 变更与联系

本说明随网页版功能更新而更新；重大变化会在页面内提示。有问题请通过项目仓库的 Issues 反馈。
